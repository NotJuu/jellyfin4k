Anime4K

Anime4K rechnet Animes in Echtzeit hoch. Im Webplayer gibt es dafür einen neuen Button (auto_awesome) bzw. die rote Taste der Fernbedienung. Fernseher, deren Grafikleistung nicht ausreicht, können das Hochrechnen vom Server erledigen lassen – der Fernseher erhält dann direkt das fertig hochgerechnete Video (z. B. in 4K).

Allgemein

Fügt den Anime4K-Button und das Menü in den Jellyfin-Webclient (Browser, LG webOS, Desktop-App) ein. Nach Änderungen die Seite neu laden.
Der Server rechnet das Video mit FFmpeg/libplacebo und Anime4K hoch (benötigt eine Vulkan-fähige GPU im Server).
Wenn deaktiviert, können nur Administratoren Geräte für Server-Upscaling freischalten.
Nur Titel mit Genre „Anime“/„Animation“ oder „anime“ im Pfad werden auf dem Server hochgerechnet.

Encoder

Benötigt FFmpeg mit libplacebo und Vulkan (jellyfin-ffmpeg 6 oder neuer erfüllt das).
Für 4K-Ausgabe in Echtzeit wird ein Hardware-Encoder dringend empfohlen. HEVC ist effizienter, wird aber nicht von jedem Browser unterstützt.
Index (z. B. 0) oder Name der GPU, die libplacebo verwenden soll. Bei mehreren GPUs oder wenn „Found no suitable device“ im Test erscheint, hier 0 eintragen.
